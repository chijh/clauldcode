# 作業ログ 2026-07-02

## 概要
つくば市の天気をテキストで聞ける Python プロジェクト「Genie」を新規作成し、GitHub リポジトリ（chijh/clauldcode）へ公開した。あわせてこのPCの Python 実行環境を整備した。

## やったこと

### 1. Genie プロジェクトの作成
- `weather_genie/`（パッケージ `genie`）を作成。つくば市（茨城県南部・JMAエリアコード `080020`）の天気を答えるテキスト対話 CLI。
- データ源: 気象庁(JMA)公式API（APIキー不要・無料）。気温はつくば市に最寄りの「土浦」観測点を優先。
- 依存なし（Python標準ライブラリのみ）。`今日 / 明日 / 明後日 / 週間 / 気温 / 雨` の質問に対応。
- 構成:
  ```
  weather_genie/
  ├── main.py            エントリポイント
  ├── README.md
  └── genie/
      ├── __init__.py
      ├── jma.py         気象庁APIクライアント（取得・解析）
      ├── assistant.py   Genie本体（意図解釈と回答生成）
      └── cli.py         コマンドライン対話UI
  ```
- 実データで動作確認済み（今日/明日/週間/降水の各クエリ）。

### 2. 不要ファイルの削除
- 初回コミット用コマンドのスクラッチ `無題1.txt` を削除。

### 3. GitHub へ push
- リモート `chijh` → `https://github.com/chijh/clauldcode.git` を追加し push。
- `origin`（`samuraiworks/chi`）はそのまま残置。
- `.gitignore` を追加し、誤って含めた `__pycache__/*.pyc` を除外。

### 4. Python 実行環境の整備
- `winget install Python.Python.3.12` で Python 3.12.10 を導入。
  - 実体: `C:\Users\cjh06\AppData\Local\Programs\Python\Python312\python.exe`
- PATH上の `python` が Microsoft Store のアプリ実行エイリアス（スタブ）を指して動かなかった問題を解消。
  - 設定 → アプリ → アプリ実行エイリアス で `python.exe` / `python3.exe` を OFF。
  - これで新規ターミナルでは本物の `python` が使えるようになった。
- 日本語出力の文字化け対策: 実行前に `$env:PYTHONIOENCODING = "utf-8"`。

### 5. ブランチ運用
- 作業ブランチを `main` → `develop` に変更し、`chijh/develop` を追跡。
- `develop` を pull（`README.md` の更新を取り込み）。
- GitHub の既定ブランチは `main` のまま（変更は Web UI が必要）。

### 6. スキル化と毎朝の自動通知
- **`/weather` プロジェクトスキル**を作成（`.claude/skills/weather/SKILL.md`）。
  つくば市の天気・気温・降水の質問で Genie CLI を実行して答える。
  ※ セッション中に作成したスキルは、Claude Code を再起動するまで `/weather` として認識されない。
- **通知スクリプト** `weather_genie/scripts/morning_notify.ps1` を作成。
  天気を取得して Windows トースト通知を表示する。
  ※ Windows PowerShell 5.1 の文字化け対策として UTF-8（BOM付き）で保存する必要がある。
- **タスクスケジューラ** に `GenieMorningWeather` を登録し、毎朝 10:00 に上記を自動実行。
  手動実行で動作確認済み（LastResult=0）。このタスクはこのPC固有でリポジトリには含まれない。
  - 管理: `Get-ScheduledTaskInfo` / `Start-ScheduledTask` / `Unregister-ScheduledTask -TaskName GenieMorningWeather`
