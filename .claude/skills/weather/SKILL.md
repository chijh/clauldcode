# weather — つくば市の天気を答える

このリポジトリの Genie CLI（`weather_genie/main.py`）を実行し、気象庁(JMA)の実データに基づいて
つくば市の天気を答える。天気は時々刻々変わるので、**記憶や推測で答えず、必ずCLIを実行**して最新値を取得する。

## 実行方法

Windows / PowerShell。文字化けを防ぐため `PYTHONIOENCODING=utf-8` を設定してから実行する。

```powershell
$env:PYTHONIOENCODING = "utf-8"
python C:\Users\cjh06\Desktop\github\weather_genie\main.py <質問>
```

`python` が見つからない場合は、実体を直接指定する（PATHのStoreスタブ対策）:
`C:\Users\cjh06\AppData\Local\Programs\Python\Python312\python.exe`

## 質問語の選び方

ユーザーの意図に応じて CLI に渡す引数を選ぶ。CLIは質問文から意図を判定するので、
ユーザーの言葉をほぼそのまま渡してよい。目安は次のとおり。

| ユーザーの質問 | 渡す引数 |
| --- | --- |
| 今日の天気は？／本日 | `今日の天気` |
| 明日は？／あした晴れる？ | `明日` |
| 明後日 | `明後日` |
| 今週／週間予報／これからの天気 | `週間` |
| 気温は？／何度？／暑い？寒い？ | `今日の気温`（対象日があれば `明日の気温` 等） |
| 雨降る？／傘いる？ | `明日は雨降る？` など「雨」を含む文 |

日付が曖昧なときは「今日」を既定にする。複数日を聞かれたら `週間` を使うとまとめて答えられる。

## 回答の作り方

1. 上表を参考に引数を決め、CLI を1回実行する。
2. CLI の出力（天気・気温・降水確率）をそのまま提示し、必要なら一言添える
   （例: 降水確率が高ければ「傘を持って行くと安心です」）。
3. CLI がエラー（気象庁APIへの接続失敗など）を返したら、その旨を正直に伝える。
   勝手に天気をでっち上げない。

## 補足

- データ源は気象庁公式API（APIキー不要・無料）。ネット接続が必要。
- 対象地域はつくば市（茨城県南部, JMAエリアコード 080020）。気温は最寄りの土浦観測点を使用。
- 発表当日は最低・最高気温が同値になることがある（気象庁の仕様）。
